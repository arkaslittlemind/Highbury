# Design documents

One study document for each finished piece of work, written to the rules of
Simplified Technical English.

- [01 Database schema, views, roles](01-database-schema-views-roles.md) - the tables, the views for the agent, the two database roles, and the migration runner
- [02 Ingest 2003-04 (StatsBomb)](02-ingest-2003-04-statsbomb.md) - the command that loads the 2003-04 season: the raw cache, the transforms, the idempotent loader, and the sanity check before the commit
- [03 Ingest 2025-26 (Understat)](03-ingest-2025-26-understat.md) - the command that loads the 2025-26 season: the mirrored y axis, the shared values of the two seasons, the facts from a second source, and the shared command parts
- [04 Aliases + data catalog](04-aliases-data-catalog.md) - the command that loads the player aliases and the data catalog: the file as the source of truth, the checks before the first write, and one transaction for the two loads
- [05 Data tools + SQL guardrails](05-data-tools-sql-guardrails.md) - the four data tools of the agent and the two locks on model-written SQL: the parser lock, the database lock, the row limit, and the search for a player name
- [06 Chart specs + MCP server](06-chart-specs-mcp-server.md) - the fifth tool, which makes a chart from a query, and the server that gives the five tools to other programs: chart specs as data, the row limit as an error, and stdio with no network port
- [07 Analyst agent + CLI](07-analyst-agent-cli.md) - the model in front of the five tools and the `ask` command: the answer contract, the prompt from live data, the two limits, the record of each tool call, and memory for a follow-up
- [08 Claim verifier](08-claim-verifier.md) - the code that checks each number of an answer against the tool output: one rule for counts and one for rates, the scan of the summary, the removed claims, and the limits of the check
- [09 Analyst API + streaming](09-analyst-api-streaming.md) - the HTTP service that streams each turn as events: the worker thread and the queue, the conversation ids, the rate limit for each address, the kept answers of the suggestions, and the log line with no visitor text
- [10 Deploy pipeline](10-deploy-pipeline.md) - the public API on AWS and the web shell on Vercel: the image, one task behind a load balancer, the stream header, the address of the visitor from a trusted proxy, and the secrets as parameters
- [11 Ask page](11-ask-page.md) - the web page where a visitor asks the analyst: the check of each payload in the browser, the reducer of a turn, the failures that end a conversation, and the screens for each result that is not a plain answer
- [12 Pitch + shot map](12-pitch-shot-map.md) - the reusable pitch and the shot map chart: an SVG in pitch units, size for xG and shape for the outcome, the attacking half only, one tab stop with arrow keys, and a summary of counts
- [13 Compare bars](13-compare-bars.md) - the chart that compares two players on shared metrics: one scale for each row, the mark for a metric of an xG model, no number made in the browser, and a layout that follows the width of its panel
- [14 Visual polish + hero](14-visual-polish-hero.md) - the hero, the "How it works" strip, and the phone layout: two enter motions from CSS classes, one global rule for reduced motion, a sticky follow-up bar, and a contrast test that reads the stylesheet
- [15 Stretch: pass network](15-stretch-pass-network.md) - the chart of who passed to whom in one 2003-04 match: SQL examples for the agent, one line for each pair, names placed below or above, a full pitch with a width cap, and a fourth suggestion chip
- [16 Evals + model comparison](16-evals-model-comparison.md) - the command that asks 15 golden questions on each model: expected values from hand-written SQL, only passed claims count, a timeout on each model call, and the decision to keep gemini-3.8-flash
- [17 Pass network polish](17-pass-network-polish.md) - the starting XI by default: substitutions stored as events, a `v_substitutions` view, a cut-off minute that comes from the SQL rows, a minimum-passes slider, and a table of the drawn links
- [18 xG timeline](18-xg-timeline.md) - the chart of the cumulative xG of both teams in one match: totals from the service and not the browser, Arsenal first, one `match_id` for all rows, a sum before the round, and axis labels in HTML
- [19 Ingest football-data.co.uk](19-ingest-football-data-co-uk.md) - every league match of both seasons: Arsenal's matches linked and never added twice, a stop on any score that differs, no new clubs, a check against the published tables, and a cache that a person can fill by hand
- [20 Points pace](20-points-pace.md) - the chart of the cumulative points of each team and season: points from the goals with the 3/1/0 rule, matches played and not the gameweek, one subquery for the chart and its claims, Arsenal first, and an xG caveat only for xG
- [21 Entity resolution](21-entity-resolution.md) - one canonical ID for each source player and team: an override first, then the source ID, then the name in the same team and season, a link only when it is certain, one player for each record of a source, and one `overrides.yaml` in place of `aliases.yaml`
- [22 Ingest FPL 2025-26](22-ingest-fpl-2025-26.md) - the FPL numbers of every player in each 2025-26 match: its own table and view, links through the feature 21 resolver and 17 overrides, a pair check and an exact goals check against Understat with one named difference, and the player search fix of 22/F-30
- [23 Evals refresh](23-evals-refresh.md) - nine golden questions for the v1.1 charts and data: each query checked on the real data before the paid run, both models run again, a failure that passes the verifier, and the decision to keep gemini-3.8-flash
- [24 Pass map (2003-04)](24-pass-map-2003-04.md) - the arrows of the passes of one player: one player for each chart, a long pass of 35 or more on the 120 x 80 pitch, one SQL filter for the chart and its claims, solid and dashed arrows with one marker for each kind, and a summary that does not give the threshold
- [Harden roles and schema checks](2026-10-11-harden-roles-and-schema-checks.md) - the fix for the seven review findings: one default permission removed, one grant added, two checks, and a settings repair
- [Request body limit and review cleanup](2026-10-13-request-body-limit-and-review-cleanup.md) - the fix for a request body of any size: a count of the bytes as the service reads them, status 413 at 16 KB, and two small repairs from the review of feature 10
- [Body limit comment and split-body test](2026-10-13-body-limit-comment-and-split-body-test.md) - the fix for two review findings of the body limit: the true reason in one comment, and a test that calls the app with a body in three messages
- [Link claims to their queries](2026-10-13-link-claims-to-their-queries.md) - the fix that joins a claim to its tool call: one field more from the service, a required field in the schema of the page, the order of the two deploys, and the outline of the row after a click
- [Filter the shot map by outcome](2026-10-14-filter-the-shot-map-by-outcome.md) - the fix that makes the legend a filter: one toggle button for each outcome, a set of hidden kinds, a summary that does not follow the filter, and the reset of the active shot
- [Landing screen with the grass hero](2026-10-14-landing-screen-grass-hero.md) - the first screen from the new design reference: the question bar in the hero, real shots in the sample chart, an enter motion that plays one time, and content that shows when the visitor scrolls to it
- [Accept both readings of a golden question](2026-10-14-accept-both-readings-of-a-golden-question.md) - the fix for a correct answer that the evals marked wrong: other fair readings as queries in `also_sql`, the closest reading for the score, a full new run, and the decision to keep gemini-3.8-flash
- [Reject sequence write functions in the SQL guard](2026-10-14-reject-sequence-write-functions-in-the-sql-guard.md) - the fix for F-01 and F-25: `nextval` and `setval` in the list of forbidden functions, a function name that must be ASCII because sqlglot writes names with `str.upper`, two independent reviews, and the deploy of the API image
- [Test that non-ASCII text outside a function name passes the guard](2026-10-14-test-that-non-ascii-text-outside-a-function-name-passes-the-guard.md) - the fix for F-26: one test that keeps the ASCII rule on function names only, with a literal and a quoted alias, and a check of the SQL that the guard writes
- [Store the event period for the starting XI window](2026-10-22-store-the-event-period-for-the-starting-xi-window.md) - the fix for F-25 and F-26: the period of each event in `events` and two views, a window that compares `(period, minute, second) < ALL`, 8 passes back in one match, and both readings of golden question q10
- [Upgrade Next.js to 16.4.3](2026-10-24-upgrade-next-js-to-16-4-3.md) - the fix for three Next.js advisories: two exact version pins, a lock file that moves only the Next.js packages, and the shadcn advisories left for a separate decision
- [Agent hook cleanup and structured-output tests](2026-10-26-agent-hook-cleanup-and-structured-output-tests.md) - the fix for F-02, F-03, F-04, and F-27: one middleware removed because LangChain clears a stale answer, two tests with a model profile for the provider path, a 21-call thread with a mutation check, and a note after a hashed archive
- [Keep a suggestion turn only after its answer is written](2026-10-26-keep-a-suggestion-turn-only-after-its-answer-is-written.md) - the fix for F-16: the answer event before the kept turn, so a text that UTF-8 cannot hold never stays as the answer of a suggestion chip, and the closure of F-23 and F-24
- [Limit a conversation to 20 turns](2026-10-26-limit-a-conversation-to-20-turns.md) - the fix for F-10: a count of the turns of each conversation, the memory free after the 20th answer, and the 404 that the web page already shows as an ended conversation
- [Refuse a CORS origin that a browser never sends](2026-10-26-refuse-a-cors-origin-that-a-browser-never-sends.md) - the fix for F-18: a broken IPv6 address as a SettingsError and not a traceback, and one comparison with the lower-case origin that a browser sends in place of three checks
- [Never cache a football-data page that is not CSV, and test the league load](2026-10-26-never-cache-a-football-data-page-that-is-not-csv-and-test-the-league-load.md) - the fix for F-28 and F-29: a check of the first row before the cache gets a download, and two tests of the full league load with a rollback that a mutation proves
- [Send a heartbeat while a turn is quiet](2026-10-26-send-a-heartbeat-while-a-turn-is-quiet.md) - the fix for F-21 after a live measurement: a ping event after 15 quiet seconds so the load balancer keeps the stream, no web change because the parser skips an unknown event, and the same run that settled F-05, F-09, and F-17
- [Give the run_sql cells an explicit output schema](2026-10-28-give-the-run-sql-cells-an-explicit-output-schema.md) - the fix for the MCP Inspector warning: a cell type that validates as `JsonValue` and publishes the six JSON types, the arrays and objects that the guard allows, and a test that finds an empty schema in any tool
