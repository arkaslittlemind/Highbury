How it works

  1. 01

    Data catalog first

    The agent reads what each season actually holds before it writes a query — so it knows 2025–26 has shots but no passes.

  2. 02

    Read-only SQL

    One SELECT per call, checked by a parser and run as a read-only role with a 5-second timeout and a row cap.

  3. 03

    Claim verifier

    Plain code checks every number against the tool output it cites. Anything unsupported is removed before you see it.
